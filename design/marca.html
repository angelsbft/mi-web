01

Paletas

Toca una paleta: toda esta página (logos, web e Instagram) cambia de color para que la veas aplicada. Las proporciones importan: el color fuerte se usa poco, solo para lo que debe llamar la atención (botones, una palabra, un detalle).

Igual que en tus referencias: una letra condensada y fuerte para los títulos, una cursiva elegante para la palabra que quieres resaltar, y una letra limpia para leer.
